\doxysubsection{Detailed Description}
Internal structures and API for parsing and executing .WIZARD binary files. 

A .WIZARD file is a structured binary package script. It contains a file header, a section header table, a variable number of sections (metadata, build, install, uninstall, purge), and a string table (strndx).

All multi-\/byte integer fields in the on-\/disk structs are big-\/endian. Use the {\ttfamily wizard\+\_\+be\texorpdfstring{$\ast$}{*}} helpers to read them portably.
