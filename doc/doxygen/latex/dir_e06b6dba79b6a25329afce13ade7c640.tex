\end{DoxyCode}

From time to time, you may not want to directly convert a value to its boolean equivalent, but explicitly check whether it looks like a boolean. E.\+g., although {\ttfamily boolean(\textquotesingle{}\doxylink{md4_8c_a96d73bbd7af15cb1fc38c3f4a3bd82e9}{F}\textquotesingle{})} returns {\ttfamily false}, the string {\ttfamily \doxylink{md4_8c_a96d73bbd7af15cb1fc38c3f4a3bd82e9}{F}} at least looks like a boolean, in contrast to something such as {\ttfamily 123} (for which {\ttfamily boolean(123)} would also return {\ttfamily false}).

To figure out whether a value can be considered to be a boolean, use the {\ttfamily is\+Booleanable} function\+:

\end{DoxyCode}
