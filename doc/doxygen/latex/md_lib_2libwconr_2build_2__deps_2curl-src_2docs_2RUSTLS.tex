\href{https://docs.rs/rustls/}{\texttt{Rustls is a TLS backend written in Rust.}}. Curl can be built to use it as an alternative to Open\+SSL or other TLS backends. We use the \href{https://github.com/rustls/rustls-ffi/}{\texttt{rustls-\/ffi C bindings}}. This version of curl depends on version v0.\+8.\+2 of rustls-\/ffi.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2RUSTLS_autotoc_md1812}{}\doxysection{\texorpdfstring{Building with rustls}{Building with rustls}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2RUSTLS_autotoc_md1812}
First, \href{https://rustup.rs/}{\texttt{install Rust}}.

Next, check out, build, and install the appropriate version of rustls-\/ffi\+: \begin{DoxyVerb}% cargo install cbindgen
% git clone https://github.com/rustls/rustls-ffi -b v0.8.2
% cd rustls-ffi
% make
% make DESTDIR=${HOME}/rustls-ffi-built/ install
\end{DoxyVerb}


Now configure and build curl with rustls\+: \begin{DoxyVerb}% git clone https://github.com/curl/curl
% cd curl
% autoreconf -fi
% ./configure --with-rustls=${HOME}/rustls-ffi-built
% make
\end{DoxyVerb}
