The curl project runs a bug bounty program in association with \href{https://www.hackerone.com}{\texttt{Hacker\+One}} and the \href{https://internetbugbounty.org}{\texttt{Internet Bug Bounty}}.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1415}{}\doxysection{\texorpdfstring{How does it work?}{How does it work?}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1415}
Start out by posting your suspected security vulnerability directly to \href{https://hackerone.com/curl}{\texttt{curl\textquotesingle{}s Hacker\+One program}}.

After you have reported a security issue, it has been deemed credible, and a patch and advisory has been made public, you may be eligible for a bounty from this program. See the \doxysectlink{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2SECURITY-PROCESS}{SECURITY-\/\+PROCESS}{0} document for how we work with security issues.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1416}{}\doxysection{\texorpdfstring{What are the reward amounts?}{What are the reward amounts?}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1416}
The curl project offers monetary compensation for reported and published security vulnerabilities. The amount of money that is rewarded depends on how serious the flaw is determined to be.

Since 2021, the Bug Bounty is managed in association with the Internet Bug Bounty and they will set the reward amounts. If it would turn out that they set amounts that are way lower than we can accept, the curl project intends to "{}top up"{} rewards.

In 2022, typical "{}\+Medium"{} rated vulnerabilities have been rewarded 2,400 USD each.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1417}{}\doxysection{\texorpdfstring{Who is eligible for a reward?}{Who is eligible for a reward?}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1417}
Everyone and anyone who reports a security problem in a released curl version that has not already been reported can ask for a bounty.

Dedicated -\/ paid for -\/ security audits that are performed in collaboration with curl developers are not eligible for bounties.

Vulnerabilities in features that are off by default and documented as experimental are not eligible for a reward.

The vulnerability has to be fixed and publicly announced (by the curl project) before a bug bounty will be considered.

Once the vulnerability has been published by curl, the researcher can request their bounty from the \href{https://hackerone.com/ibb}{\texttt{Internet Bug Bounty}}.

Bounties need to be requested within twelve months from the publication of the vulnerability.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1418}{}\doxysection{\texorpdfstring{Product vulnerabilities only}{Product vulnerabilities only}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1418}
This bug bounty only concerns the curl and libcurl products and thus their respective source codes -\/ when running on existing hardware. It does not include curl documentation, curl websites, or other curl related infrastructure.

The curl security team is the sole arbiter if a reported flaw is subject to a bounty or not.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1419}{}\doxysection{\texorpdfstring{How are vulnerabilities graded?}{How are vulnerabilities graded?}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1419}
The grading of each reported vulnerability that makes a reward claim will be performed by the curl security team. The grading will be based on the CVSS (Common Vulnerability Scoring System) 3.\+0.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1420}{}\doxysection{\texorpdfstring{How are reward amounts determined?}{How are reward amounts determined?}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1420}
The curl security team gives the vulnerability a score or severity level, as mentioned above. The actual monetary reward amount is decided and paid by the Internet Bug Bounty..\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1421}{}\doxysection{\texorpdfstring{Regarding taxes, etc. on the bounties}{Regarding taxes, etc. on the bounties}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUG-BOUNTY_autotoc_md1421}
In the event that the individual receiving a bug bounty needs to pay taxes on the reward money, the responsibility lies with the receiver. The curl project or its security team never actually receive any of this money, hold the money, or pay out the money.
