This is the internal module for creating and handling "{}dynamic buffers"{}. This means buffers that can be appended to, dynamically and grow to adapt.

There will always be a terminating zero put at the end of the dynamic buffer.

The {\ttfamily struct \doxylink{structdynbuf}{dynbuf}} is used to hold data for each instance of a dynamic buffer. The members of that struct {\bfseries{MUST NOT}} be accessed or modified without using the dedicated dynbuf API.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2DYNBUF_autotoc_md1590}{}\doxysection{\texorpdfstring{{\ttfamily Curl\+\_\+dyn\+\_\+init}}{{\ttfamily Curl\+\_\+dyn\+\_\+init}}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2DYNBUF_autotoc_md1590}
