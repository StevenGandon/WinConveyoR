\doxysubsection{Detailed Description}
On-\/disk layout of the .WIZARD file header (27 bytes, big-\/endian fields). 

Always located at offset 0 of the file. All integer fields must be read through the {\ttfamily wizard\+\_\+be\texorpdfstring{$\ast$}{*}} helpers to handle endianness correctly.
