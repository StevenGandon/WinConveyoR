Groups multiple \doxylink{classQCPBars}{QCPBars} together so they appear side by side. 



When showing multiple \doxylink{classQCPBars}{QCPBars} in one plot which have bars at identical keys, it may be desirable to have them appearing next to each other at each key. This is what adding the respective \doxylink{classQCPBars}{QCPBars} plottables to a \doxylink{classQCPBarsGroup}{QCPBars\+Group} achieves. (An alternative approach is to stack them on top of each other, see QCPBars\+::move\+Above.)\hypertarget{classQCPBarsGroup_qcpbarsgroup-usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classQCPBarsGroup_qcpbarsgroup-usage}
