\DoxyCodeLine{stringify(obj,\ serializer,\ indent,\ decycler)}

\end{DoxyCode}


The first three arguments are the same as to JSON.\+stringify. The last is an argument that\textquotesingle{}s only used when the object has been seen already.

The default {\ttfamily decycler} function returns the string {\ttfamily \textquotesingle{}\mbox{[}Circular\mbox{]}\textquotesingle{}}. If, for example, you pass in {\ttfamily function(k,v)\{\}} (return nothing) then it will prune cycles. If you pass in {\ttfamily function(k,v)\{ return \{foo\+: \textquotesingle{}bar\textquotesingle{}\}\}}, then cyclical objects will always be represented as {\ttfamily \{"{}foo"{}\+:"{}bar"{}\}} in the result.
