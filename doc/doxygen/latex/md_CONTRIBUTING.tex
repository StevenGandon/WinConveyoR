The typical workflow for contributing is\+:


\begin{DoxyEnumerate}
\item Create or find an issue to work on
\item Create a new branch from {\ttfamily dev}
\item Make your changes following our code standards
\item Write/update tests for your changes
\item Commit your changes with proper commit messages
\item Push your branch and create a pull request
\item Address review feedback
\item Celebrate when your PR is merged!

Your issue should include\+:

{\bfseries{Title}}\+: Clear and concise description

{\bfseries{Description}}\+:
\begin{DoxyItemize}
\item {\bfseries{Brief}}\+: Short summary of the issue
\item {\bfseries{Context}}\+: Why is this needed?
\item {\bfseries{Proposed Solution}}\+: How do you plan to address it?
\item {\bfseries{Tasks}}\+: Breakdown of work into checkboxes
\begin{DoxyItemize}
\item \mbox{[} \mbox{]} Task 1
\item \mbox{[} \mbox{]} Task 2
\item \mbox{[} \mbox{]} Task 3
\end{DoxyItemize}
\end{DoxyItemize}

{\bfseries{Brief Description}}\+:
\begin{DoxyItemize}
\item Start with a prefix in square brackets
\item Keep it concise (50 characters or less)
\item Use imperative mood ("{}add feature"{} not "{}added feature"{})
\item Don\textquotesingle{}t end with a period
\end{DoxyItemize}

{\bfseries{Detailed Description}} (optional but recommended)\+:
\begin{DoxyItemize}
\item Add a blank line after the brief
\item Explain the "{}what"{} and "{}why"{}, not the "{}how"{}
\item Wrap lines at 72 characters
\item Reference issues using {\ttfamily \#issue-\/number}
\end{DoxyItemize}\hypertarget{md_CONTRIBUTING_autotoc_md21}{}\doxysubsection{\texorpdfstring{Commit Examples}{Commit Examples}}\label{md_CONTRIBUTING_autotoc_md21}
