compare two semver version strings, returning -\/1, 0, or 1

The return value can be fed straight into {\ttfamily \mbox{[}\mbox{]}.sort}.

\href{http://travis-ci.org/substack/semver-compare}{\texttt{}}\hypertarget{md_gui_2node__modules_2semver-compare_2readme_autotoc_md1260}{}\doxysection{\texorpdfstring{example}{example}}\label{md_gui_2node__modules_2semver-compare_2readme_autotoc_md1260}
