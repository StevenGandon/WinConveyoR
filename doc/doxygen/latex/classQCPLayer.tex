\doxysubsection{Detailed Description}
A layer that may contain objects, to control the rendering order. 

The Layering system of \doxylink{classQCustomPlot}{QCustom\+Plot} is the mechanism to control the rendering order of the elements inside the plot.

It is based on the two classes \doxylink{classQCPLayer}{QCPLayer} and \doxylink{classQCPLayerable}{QCPLayerable}. \doxylink{classQCustomPlot}{QCustom\+Plot} holds an ordered list of one or more instances of \doxylink{classQCPLayer}{QCPLayer} (see QCustom\+Plot\+::add\+Layer, QCustom\+Plot\+::layer, QCustom\+Plot\+::move\+Layer, etc.). When replotting, \doxylink{classQCustomPlot}{QCustom\+Plot} goes through the list of layers bottom to top and successively draws the layerables of the layers into the paint buffer(s).

A \doxylink{classQCPLayer}{QCPLayer} contains an ordered list of \doxylink{classQCPLayerable}{QCPLayerable} instances. \doxylink{classQCPLayerable}{QCPLayerable} is an abstract base class from which almost all visible objects derive, like axes, grids, graphs, items, etc.\hypertarget{classQCPLayer_qcplayer-defaultlayers}{}\doxysubsection{\texorpdfstring{Default layers}{Default layers}}\label{classQCPLayer_qcplayer-defaultlayers}
Initially, \doxylink{classQCustomPlot}{QCustom\+Plot} has six layers\+: "{}background"{}, "{}grid"{}, "{}main"{}, "{}axes"{}, "{}legend"{} and "{}overlay"{} (in that order). On top is the "{}overlay"{} layer, which only contains the \doxylink{classQCustomPlot}{QCustom\+Plot}\textquotesingle{}s selection rect (QCustom\+Plot\+::selection\+Rect). The next two layers "{}axes"{} and "{}legend"{} contain the default axes and legend, so they will be drawn above plottables. In the middle, there is the "{}main"{} layer. It is initially empty and set as the current layer (see QCustom\+Plot\+::set\+Current\+Layer). This means, all new plottables, items etc. are created on this layer by default. Then comes the "{}grid"{} layer which contains the \doxylink{classQCPGrid}{QCPGrid} instances (which belong tightly to \doxylink{classQCPAxis}{QCPAxis}, see QCPAxis\+::grid). The Axis rect background shall be drawn behind everything else, thus the default \doxylink{classQCPAxisRect}{QCPAxis\+Rect} instance is placed on the "{}background"{} layer. Of course, the layer affiliation of the individual objects can be changed as required (QCPLayerable\+::set\+Layer).\hypertarget{classQCPLayer_qcplayer-ordering}{}\doxysubsection{\texorpdfstring{Controlling the rendering order via layers}{Controlling the rendering order via layers}}\label{classQCPLayer_qcplayer-ordering}
Controlling the ordering of layerables in the plot is easy\+: Create a new layer in the position you want the layerable to be in, e.\+g. above "{}main"{}, with QCustom\+Plot\+::add\+Layer. Then set the current layer with QCustom\+Plot\+::set\+Current\+Layer to that new layer and finally create the objects normally. They will be placed on the new layer automatically, due to the current layer setting. Alternatively you could have also ignored the current layer setting and just moved the objects with QCPLayerable\+::set\+Layer to the desired layer after creating them.

It is also possible to move whole layers. For example, If you want the grid to be shown in front of all plottables/items on the "{}main"{} layer, just move it above "{}main"{} with QCustom\+Plot\+::move\+Layer.

The rendering order within one layer is simply by order of creation or insertion. The item created last (or added last to the layer), is drawn on top of all other objects on that layer.

When a layer is deleted, the objects on it are not deleted with it, but fall on the layer below the deleted layer, see QCustom\+Plot\+::remove\+Layer.\hypertarget{classQCPLayer_qcplayer-buffering}{}\doxysubsection{\texorpdfstring{Replotting only a specific layer}{Replotting only a specific layer}}\label{classQCPLayer_qcplayer-buffering}
If the layer mode (set\+Mode) is set to lm\+Buffered, you can replot only this specific layer by calling replot. In certain situations this can provide better replot performance, compared with a full replot of all layers. Upon creation of a new layer, the layer mode is initialized to lm\+Logical. The only layer that is set to lm\+Buffered in a new \doxylink{classQCustomPlot}{QCustom\+Plot} instance is the "{}overlay"{} layer, containing the selection rect.
