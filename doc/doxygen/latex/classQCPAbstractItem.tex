The abstract base class for all items in a plot.  




\doxysubsection{Detailed Description}
The abstract base class for all items in a plot. 

In \doxylink{classQCustomPlot}{QCustom\+Plot}, items are supplemental graphical elements that are neither plottables (\doxylink{classQCPAbstractPlottable}{QCPAbstract\+Plottable}) nor axes (\doxylink{classQCPAxis}{QCPAxis}). While plottables are always tied to two axes and thus plot coordinates, items can also be placed in absolute coordinates independent of any axes. Each specific item has at least one \doxylink{classQCPItemPosition}{QCPItem\+Position} member which controls the positioning. Some items are defined by more than one coordinate and thus have two or more \doxylink{classQCPItemPosition}{QCPItem\+Position} members (For example, \doxylink{classQCPItemRect}{QCPItem\+Rect} has {\itshape top\+Left} and {\itshape bottom\+Right}).

This abstract base class defines a very basic interface like visibility and clipping. Since this class is abstract, it can\textquotesingle{}t be instantiated. Use one of the subclasses or create a subclass yourself to create new items.

\hypertarget{classQCPAbstractItem_items-clipping}{}\doxysubsection{\texorpdfstring{Clipping}{Clipping}}\label{classQCPAbstractItem_items-clipping}
Items are by default clipped to the main axis rect (they are only visible inside the axis rect). To make an item visible outside that axis rect, disable clipping via set\+Clip\+To\+Axis\+Rect(false).

On the other hand if you want the item to be clipped to a different axis rect, specify it via set\+Clip\+Axis\+Rect. This clip\+Axis\+Rect property of an item is only used for clipping behaviour, and in principle is independent of the coordinate axes the item might be tied to via its position members (QCPItem\+Position\+::set\+Axes). \hypertarget{classQCPAbstractItem_items-drawing}{}\doxysubsubsection{\texorpdfstring{The draw function}{The draw function}}\label{classQCPAbstractItem_items-drawing}
