\doxysubsection{Detailed Description}
\hypertarget{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1602}{}\doxysubsection{\texorpdfstring{libcurl examples}{libcurl examples}}\label{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1602}
This directory is for libcurl programming examples. They are meant to show some simple steps on how you can build your own application to take full advantage of libcurl.

If you end up with other small but still useful example sources, please mail them for submission in future packages and on the website.\hypertarget{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1603}{}\doxysubsubsection{\texorpdfstring{Building}{Building}}\label{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1603}
The {\ttfamily Makefile.\+example} is an example Makefile that could be used to build these examples. Just edit the file according to your system and requirements first.

Most examples should build fine using a command line like this\+: \begin{DoxyVerb}`curl-config --cc --cflags --libs` -o example example.c
\end{DoxyVerb}


Some compilers do not like having the arguments in this order but instead want you do reorganize them like\+: \begin{DoxyVerb}`curl-config --cc` -o example example.c `curl-config --cflags --libs`
\end{DoxyVerb}


{\bfseries{Please}} do not use the {\ttfamily curl.\+se} site as a test target for your libcurl applications/experiments. Even if some of the examples use that site as a URL at some places, it does not mean that the URLs work or that we expect you to actually torture our website with your tests. Thanks.\hypertarget{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1604}{}\doxysubsubsection{\texorpdfstring{Examples}{Examples}}\label{dir_1ef6c89235958d9530183f5e610e1189_autotoc_md1604}
Each example source code file is designed to be and work stand-\/alone and rather self-\/explanatory. The examples may at times lack the level of error checks you need in a real world, but that is then only for the sake of readability\+: to make the code smaller and easier to follow.
