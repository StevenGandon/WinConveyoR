Unzip written in pure Java\+Script. Extracts a zip into a directory. Available as a library or a command line program.

Uses the \href{http://npmjs.org/yauzl}{\texttt{{\ttfamily yauzl}}} ZIP parser.

\href{https://npm.im/extract-zip}{\texttt{}} \href{https://github.com/standard/standard}{\texttt{}} \href{https://github.com/maxogden/extract-zip/actions?query=workflow\%3ACI}{\texttt{}}\hypertarget{dir_cfc221be2e3eea78568fbe669f71f0eb_autotoc_md490}{}\doxysubsection{\texorpdfstring{Installation}{Installation}}\label{dir_cfc221be2e3eea78568fbe669f71f0eb_autotoc_md490}
