\doxysubsection{Detailed Description}
A plottable representing a bar chart in a plot. 



To plot data, assign it with the set\+Data or add\+Data functions.\hypertarget{classQCPBars_qcpbars-appearance}{}\doxysubsection{\texorpdfstring{Changing the appearance}{Changing the appearance}}\label{classQCPBars_qcpbars-appearance}
The appearance of the bars is determined by the pen and the brush (set\+Pen, set\+Brush). The width of the individual bars can be controlled with set\+Width\+Type and set\+Width.

Bar charts are stackable. This means, two \doxylink{classQCPBars}{QCPBars} plottables can be placed on top of each other (see QCPBars\+::move\+Above). So when two bars are at the same key position, they will appear stacked.

If you would like to group multiple \doxylink{classQCPBars}{QCPBars} plottables together so they appear side by side as shown below, use \doxylink{classQCPBarsGroup}{QCPBars\+Group}.
