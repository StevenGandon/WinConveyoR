Curl\+\_\+saferealloc(ptr, size)

Does a normal \doxylink{curl__memory_8h_aa568500a9ca507b5a53de5372c81f26a}{realloc()}, but will free the data pointer if the realloc fails. If \textquotesingle{}size\textquotesingle{} is non-\/zero, it will free the data and return a failure.

This convenience function is provided and used to help us avoid a common mistake pattern when we could pass in a zero, catch the NULL return and end up free\textquotesingle{}ing the memory twice.
