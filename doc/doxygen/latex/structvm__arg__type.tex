\doxysubsection{Detailed Description}
Full type descriptor for a VM argument. 

Combines a base type with an array flag. When {\ttfamily is\+\_\+array} is non-\/zero the argument is prefixed in the bytecode stream by a 4-\/byte element count (see Wizard\+Argument\+Array).
