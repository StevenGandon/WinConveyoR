Get the {\ttfamily \doxylink{data-binary_8d_a73d1d2257c0428f3cbe588f0ac996fad}{stream}} as a buffer.

It honors the {\ttfamily max\+Buffer} option as above, but it refers to byte length rather than string length.\hypertarget{dir_6e1e50ba25eeb432b4a78efa3b99d387_autotoc_md687}{}\doxysubsubsection{\texorpdfstring{get\+Stream.\+array(stream, options?)}{get\+Stream.\+array(stream, options?)}}\label{dir_6e1e50ba25eeb432b4a78efa3b99d387_autotoc_md687}
Get the {\ttfamily \doxylink{data-binary_8d_a73d1d2257c0428f3cbe588f0ac996fad}{stream}} as an array of values.

It honors both the {\ttfamily max\+Buffer} and {\ttfamily \doxylink{compressed_8d_ac0773d551ebc1033cd05b56897a6c744}{encoding}} options. The behavior changes slightly based on the encoding chosen\+:


\begin{DoxyItemize}
\item When {\ttfamily \doxylink{compressed_8d_ac0773d551ebc1033cd05b56897a6c744}{encoding}} is unset, it assumes an \href{https://nodesource.com/blog/understanding-object-streams/}{\texttt{object mode stream}} and collects values emitted from {\ttfamily \doxylink{data-binary_8d_a73d1d2257c0428f3cbe588f0ac996fad}{stream}} unmodified. In this case {\ttfamily max\+Buffer} refers to the number of items in the array (not the sum of their sizes).
\item When {\ttfamily \doxylink{compressed_8d_ac0773d551ebc1033cd05b56897a6c744}{encoding}} is set to {\ttfamily \doxylink{htmltitle_8cpp_ab3d71a3630661054e58116e2249c2e9e}{buffer}}, it collects an array of buffers. {\ttfamily max\+Buffer} refers to the summed byte lengths of every buffer in the array.
\item When {\ttfamily \doxylink{compressed_8d_ac0773d551ebc1033cd05b56897a6c744}{encoding}} is set to anything else, it collects an array of strings. {\ttfamily max\+Buffer} refers to the summed character lengths of every string in the array.
\end{DoxyItemize}\hypertarget{dir_6e1e50ba25eeb432b4a78efa3b99d387_autotoc_md688}{}\doxysubsection{\texorpdfstring{Errors}{Errors}}\label{dir_6e1e50ba25eeb432b4a78efa3b99d387_autotoc_md688}
If the input stream emits an {\ttfamily \doxylink{retry-all-errors_8d_a15465fc80b6245852b14c0ca6a48c4fb}{error}} event, the promise will be rejected with the error. The buffered data will be attached to the {\ttfamily buffered\+Data} property of the error.
