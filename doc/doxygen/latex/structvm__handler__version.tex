\doxysubsection{Detailed Description}
Associates a handler table with a format version. 

The global handler registry is a NULL-\/table-\/terminated array of these structs, sorted by ascending version. The VM picks the entry with the highest version that does not exceed the file\textquotesingle{}s format version.
