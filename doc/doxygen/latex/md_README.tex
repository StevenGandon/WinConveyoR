 Win\+ConveyoR is an advanced package manager for Windows, designed to modernise the software ecosystem and offer an experience similar to Linux managers (apt, pacman, dnf, etc.).

The project aims to fill the gap for a comprehensive, powerful and extensible tool that enables\+:


\begin{DoxyItemize}
\item Consistent dependency management,
\item The creation, compilation and distribution of packages,
\item Strong integration with Windows internal mechanisms,
\item Extension via a public API, a low-\/level library and a community marketplace.
\end{DoxyItemize}

This project is being developed as part of the Technical track of the Epitech Innovative Project and is designed to be highly configurable, secure, modular and scalable for both users and third-\/party developers.\hypertarget{md_README_autotoc_md147}{}\doxysection{\texorpdfstring{Badges}{Badges}}\label{md_README_autotoc_md147}
