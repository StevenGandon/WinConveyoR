This is an internal module for handling buffer references. A referenced buffer is associated with its destructor function that is implicitly called when the reference is invalidated. Once referenced, a buffer cannot be reallocated.

A data length is stored within the reference for binary data handling purposes; it is not used by the bufref API.

The {\ttfamily struct \doxylink{structbufref}{bufref}} is used to hold data referencing a buffer. The members of that structure {\bfseries{MUST NOT}} be accessed or modified without using the dedicated bufref API.\hypertarget{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUFREF_autotoc_md1408}{}\doxysection{\texorpdfstring{{\ttfamily init}}{{\ttfamily init}}}\label{md_lib_2libwconr_2build_2__deps_2curl-src_2docs_2BUFREF_autotoc_md1408}

Initializes a {\ttfamily \doxylink{structbufref}{bufref}} structure. This function {\bfseries{MUST}} be called before any other operation is performed on the structure.

Releases the previously referenced buffer, then duplicates the {\ttfamily length}-\/byte {\ttfamily \doxylink{structdata}{data}} into a buffer allocated via {\ttfamily \doxylink{curl__memory_8h_a2eb0b03d1a9de9615a291b1205969069}{malloc()}} and references the latter associated with destructor {\ttfamily \doxylink{curl_8h_a87dca8b22dd0cba4eaa880bdf87b8805}{curl\+\_\+free()}}.
