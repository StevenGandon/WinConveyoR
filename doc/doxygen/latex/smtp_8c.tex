Parse the fully qualified mailbox address into a local address part and the host name, converting the host name to an IDN A-\/label, as per RFC-\/5890, if necessary.

Parameters\+:

conn \mbox{[}in\mbox{]} -\/ The connection handle. fqma \mbox{[}in\mbox{]} -\/ The fully qualified mailbox address (which may or may not contain UTF-\/8 characters). address \mbox{[}in/out\mbox{]} -\/ A new allocated buffer which holds the local address part of the mailbox. This buffer must be free\textquotesingle{}ed by the caller. host \mbox{[}in/out\mbox{]} -\/ The host name structure that holds the original, and optionally encoded, host name. \doxylink{url_8c_a6896df03e3c71bee5d0798776df2911b}{Curl\+\_\+free\+\_\+idnconverted\+\_\+hostname()} must be called once the caller has finished with the structure.

Returns CURLE\+\_\+\+OK on success.

Notes\+:
