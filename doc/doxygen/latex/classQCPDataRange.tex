\doxysubsection{Detailed Description}
Describes a data range given by begin and end index. 

\doxylink{classQCPDataRange}{QCPData\+Range} holds two integers describing the begin (set\+Begin) and end (set\+End) index of a contiguous set of data points. The end index points to the data point above the last data point that\textquotesingle{}s part of the data range, similarly to the nomenclature used in standard iterators.

Data Ranges are not bound to a certain plottable, thus they can be freely exchanged, created and modified. If a non-\/contiguous data set shall be described, the class \doxylink{classQCPDataSelection}{QCPData\+Selection} is used, which holds and manages multiple instances of \doxylink{classQCPDataRange}{QCPData\+Range}. In most situations, \doxylink{classQCPDataSelection}{QCPData\+Selection} is thus used.

Both \doxylink{classQCPDataRange}{QCPData\+Range} and \doxylink{classQCPDataSelection}{QCPData\+Selection} offer convenience methods to work with them, e.\+g. bounded, expanded, intersects, intersection, adjusted, contains. Further, addition and subtraction operators (defined in \doxylink{classQCPDataSelection}{QCPData\+Selection}) can be used to join/subtract data ranges and data selections (or mixtures), to retrieve a corresponding \doxylink{classQCPDataSelection}{QCPData\+Selection}.

QCustom\+Plot\textquotesingle{}s data selection mechanism is based on \doxylink{classQCPDataSelection}{QCPData\+Selection} and \doxylink{classQCPDataRange}{QCPData\+Range}.

\begin{DoxyNote}{Note}
Do not confuse \doxylink{classQCPDataRange}{QCPData\+Range} with \doxylink{classQCPRange}{QCPRange}. A \doxylink{classQCPRange}{QCPRange} describes an interval in floating point plot coordinates, e.\+g. the current axis range. 
\end{DoxyNote}
