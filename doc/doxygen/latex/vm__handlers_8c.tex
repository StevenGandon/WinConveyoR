Looks up the handler for the given instruction name and format version. 

Selects the most recent handler table whose version does not exceed {\ttfamily version}, then searches linearly for a matching name.


\begin{DoxyParams}[1]{Parameters}

\hline

\hline
\end{DoxyParams}
