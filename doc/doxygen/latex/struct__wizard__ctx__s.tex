\doxysubsection{Detailed Description}
Runtime context for an open .WIZARD file. 

Created by \doxylink{wizard__private_8h_a8da5c6a7c3523dd6ad3477b2451d22bc}{wizard\+\_\+open} and destroyed by \doxylink{wizard__private_8h_a56d2c1efb439f13289c395826d6893b7}{wizard\+\_\+close}. The file is memory-\/mapped for the lifetime of the context; all raw struct pointers are views into the mapped region and must not be freed individually.
