\doxylink{tool__formparse_8c_afe4683cb17b527e0638a05cba4cb0876}{formparse()}

Reads a \textquotesingle{}name=value\textquotesingle{} parameter and builds the appropriate linked list.

If the value is of the form \textquotesingle{}\texorpdfstring{$<$}{<}filename\textquotesingle{}, field data is read from the given file.

Specify files to upload with \textquotesingle{}name=@filename\textquotesingle{}, or \textquotesingle{}name="{}filename"{}\textquotesingle{} in case the filename contain \textquotesingle{},\textquotesingle{} or \textquotesingle{};\textquotesingle{}. Supports specified given Content-\/\+Type of the files. Such as \textquotesingle{};type=$<$content-\/type$>$\textquotesingle{}.  \+If literal\+\_\+value is set, any initial \textquotesingle{}@\textquotesingle{} or \textquotesingle{}$<$\textquotesingle{} in the value string loses its special meaning, as does any embedded \textquotesingle{};type=\textquotesingle{}.  \+You may specify more than one file for a single name (field). Specify multiple files by writing it like\+:  \textquotesingle{}name=@filename,filename2,filename3\textquotesingle{}  or use double-\/quotes quote the filename\+:  \textquotesingle{}name=@"{}filename"{},"{}filename2"{},"{}filename3"{}\textquotesingle{}  \+If you want content-\/types specified for each too, write them like\+:  \textquotesingle{}name=@filename;type=image/gif,filename2,filename3\textquotesingle{}  \+If you want custom headers added for a single part, write them in a separate file and do like this\+:  \textquotesingle{}name=foo;headers= not \textquotesingle{}name=@filemame;headers=  \+To upload a file, but to fake the file name that will be included in the formpost, do like this\+:  \textquotesingle{}name=@filename;filename=/dev/null\textquotesingle{} or quote the faked filename like\+: \textquotesingle{}name=@filename;filename="{}play, play, and play.\+txt"{}\textquotesingle{}  \+If filename/path contains \textquotesingle{},\textquotesingle{} or \textquotesingle{};\textquotesingle{}, it must be quoted by double-\/quotes, else curl will fail to figure out the correct filename. if the filename tobe quoted contains \textquotesingle{}"{}\textquotesingle{} or \textquotesingle{}\textbackslash{}\textquotesingle{}, \textquotesingle{}"{}\textquotesingle{} and \textquotesingle{}\textbackslash{}\textquotesingle{} must be escaped by backslash.
