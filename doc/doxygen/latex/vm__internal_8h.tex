\doxysubsection{Detailed Description}
Internal types and API for the wizard bytecode virtual machine. 

The wizard VM interprets the bytecode stored in the code sections of a .WIZARD file (build, install, uninstall, purge). An instruction set is loaded from an XML file at VM initialisation time; at runtime each opcode is decoded, its arguments resolved through the string table, and a registered C handler is called to perform the actual operation.

This header is private to libwconr and must not be included by consumers of the public API.

Decodes a single instruction argument from the bytecode stream. 

Advances {\ttfamily ip} by the number of bytes consumed. For array arguments, reads the 4-\/byte element count first. String arguments are resolved through the .WIZARD string table in {\ttfamily ctx}; all other types are read directly from {\ttfamily data}.

The caller must release the decoded value with \doxylink{vm__decode_8c_a7c40df2d1c68ecfb6b23a0f38dce3c9a}{vm\+\_\+free\+\_\+args} when done.
