Installation

Developpement Tools

To build the project you will need the current developpement tools:

  • Visual Studio
  • MSVC-2022 v143
  • vcpkg
  • git
  • QT Extension for Visual Studio

Here are the steps to install them:

  • Visual Studio:
    Via the command line (powershell.exe, cmd.exe, ...):

    winget install --id=Microsoft.VisualStudio.2022.Professional -e

    Via the GUI installer:
    Download link

  • MSVC-2022 v143:
    On the visual studio installer click "Modify" on the current Visual Studio Installation.

    Select the "Individual component" tab at the top.

    Search for MSVC v143 - VS 2022 C++ x64/x86 build tools (Latest) and select it.

    Search for C++ ATL For latest v143 build tools (x86 & x64) and select it.

    Search for the latest Windows 11 SDK if none is already install and select it.

    Click the modify button on the bottom right to start the installation.

  • vcpkg:
    On the visual studio installer click "Modify" on the current Visual Studio Installation.

    Select the "Individual component" tab at the top.

    Search for vcpkg package manager and select it.

    Click the modify button on the bottom right to start the installation.

  • git:
    Via the command line (powershell.exe, cmd.exe, ...):

    Windows:
    winget install --id=Git.Git -e
    Fedora based:
    sudo dnf install git
    Arch based:
    sudo pacman -S git
    Debian based:
    sudo apt-get install git

    Via the GUI installer:
    Download link

  • QT extension:
    Open a project in visual studio (preferably the Beamage project (to install follow the Project installation steps))

    Select on the top bar extensions > Manage extensions...

    Now in the tab that opened select the Browse tab

    In the search box write Qt Visual Studio Tools (or if you want it via the web installer: https://marketplace.visualstudio.com/items?itemName=TheQtCompany.QtVisualStudioTools2022)

    Install it by clicking "Install" (or if you downloaded the web installer double click on the newly downloaded file)

    Restart Visual studio

    If you already installed QT (if not do the other installation steps and come back here) you can now configure the extension by going to (on the top bar): extensions > Qt VS Tools > Qt Versions

    In the newly opened tab click on "Add" and select the newly added row, in Name enter "6.9_msvc2022", in Host select "Windows", in Compiler select "msvc", in Location select the file path to your Qmake installation (usually something like C:\QT\6.9.0\msvc2022_64\bin\qmake.exe).

    Then Verify if it match with the Qt installation set in the project key 'Qt Installation' at Project > Properties > Qt Project settings

Dependencies

To build the project you will need the current dependencies:

  • QT6
  • ROOT6

Here are the steps to install them:

  • QT6:
    Download the installer: QT6 Installer
    Follow the instruction given by the installer.
    When prompted with the installation configuration interface, select : Qt 6.9 > MSVC 2022 64-bit
  • ROOT6:
    Download the installer: ROOT6 Installer
    Follow the instruction given and select Add ROOT to the system PATH for current user.
    When prompted with the installation configuration interface, select : C++ Headers and ROOT Libraries

Project

Now you can install the project with the below steps:

  • Clone the repository using git

    Github Desktop:

    Loggin to the Git account linked to the Beamage repository.

    You can now clone the repository:

    Select the repository beamage.git of the ai4r1 organization on your Github desktop interface and clone it to your local machine.

    Github CLI:

    Setup your ssh key on your local machine using ssh, and link it on your git profil on your account linked to the Beamage repository.

    You can now clone the repository:

    git clone git@gitlab.com:ai4r1/beamage.git
  • You are now ready to follow the compilation steps.
