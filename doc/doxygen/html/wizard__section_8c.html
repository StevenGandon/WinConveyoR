Resolves a string table entry by its byte offset.

The returned pointer is a non-owning view into the memory-mapped file. The string is not NUL-terminated on disk; use len_out to bound reads.

Parameters
[in]ctxOpen wizard context.
[in]strndx_offsetByte offset from strndx_base to the desired entry.
[out]str_outSet to the start of the string bytes on success.
[out]len_outSet to the string length in bytes on success.
Returns
0 on success, -1 if any argument is NULL or bounds are violated.
