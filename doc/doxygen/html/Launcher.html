Tool - Launcher

"launcher", the intermediary program used in both Beamage and Beavacq to setup environnement before launching both programs allowing to define custom installation of libs like ROOT.

How to build "launcher" ?

Requierments

  • CMake
  • MSVC tools (including a C compiler, the default windows LIBC bindings)

Compilation (optionnal if you already have a build)

  • cmake -B build -DENABLE_WARNINGS=ON
  • cmake –build build –config Release
  • cp ./build/Release/bealauncher.exe ./bealauncher.exe

Configuration

  • Create a file named config.cfg

  • add inside config.cfg a line containing:

    path_expand = ... (a string that is going to be added to $env:PATH)

    example: path_expand = .\my_custom_root_path\root_v6.36.02\bin

  • add inside config.cfg on a new line:

    env_expand = ... (a list that will be added at $env:key=value)

    example: env_expand = [ROOTSYS=.\my_custom_root_path\root_v6.36.02, ROOTETC=.\my_custom_root_path\root_v6.36.02\etc]

  • add inside config.cfg on a new line:

    binary_path = ... (a string corresponding to the path to the binary that will be executed)

    example: binary_path = ..\x64\Release\Beamage.exe

  • Full example :
    ~$ cat config.cfg
    path_expand = .\my_custom_root_path\root_v6.36.02\bin
    env_expand = [ROOTSYS=.\my_custom_root_path\root_v6.36.02, ROOTETC=.\my_custom_root_path\root_v6.36.02\etc]
    binary_path = ..\x64\Release\Beamage.exe
