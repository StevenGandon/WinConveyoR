Disassembles a section's bytecode and prints it to stdout.

Decodes each instruction in order, printing its file offset, index, mnemonic name, and decoded argument values.

[in]ctxOpen wizard context.
[in]sectionSection to disassemble.
Returns

int wizard_vm_exec ( struct _wizard_vm_s *  vm,
struct _wizard_ctx_s *  ctx,
const struct _wizard_section_entry_raw_s *  section 
)

Executes the bytecode contained in a section using the wizard VM.

Selects the instruction set whose version matches the file's format version, then interprets each instruction sequentially. Execution stops on the first unrecognised opcode or handler error.

Parameters
[in]vmInitialised wizard VM.
[in]ctxOpen wizard context providing the string table and file data.
[in]sectionSection entry whose content will be executed.
Returns
0 on success, -1 on any failure.

◆ wizard_vm_init()

struct _wizard_vm_s * wizard_vm_init ( const char *  instructions_dir)

Creates and initialises a wizard VM by loading instruction XML files from instructions_dir.

Loads every XML file listed in the internal vm_xml_files table. At least one instruction set must load successfully; otherwise NULL is returned.

Parameters
[in]instructions_dirDirectory containing instruction XML files.
Returns
Pointer to a new VM, or NULL on failure.
