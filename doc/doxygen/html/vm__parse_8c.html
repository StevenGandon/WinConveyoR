Parses a wizard instruction XML file and fills an instruction set.

Accepts either a root <wizard> element (with a nested <instructions> child) or a bare <instructions> root. The version attribute of the <instructions> element is required.

Parameters
[in]pathPath to the XML file on disk.
[out]isetInstruction set struct to populate. Must be pre-allocated by the caller; its fields will be initialised here.
Returns
0 on success (at least one opcode loaded), -1 on any parse or allocation failure.
