Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

unreleased

Added

  • Decay correction for activity
  • Select and change isotope and time reference
  • Event version 4 with numbering
  • Export ROI event number in ROOT entry list format
  • Opening the image in different mode (Count, MeanTime, MeanData)
  • Adding the possibility to filter the event based on an list event entry
  • Adding the projection and area managment on ROIs, and link to report
  • Add the possibility to define mixtures of radioelements in ROIs

Fixed

  • Minor bug in file reading
  • Isotope deconvolution based on charge was not working
  • Cancel button when closing beamage actually cancel the action
  • Invert image horizontal and vertical flip

Changed

  • Creation a new image from ROI, add the possibility to have more than one ROI selected
  • Change the dialog for opening the image to add options such as visible scene, entire scene or selected ROI
  • Workspace file are now created in the temp folder and deleted when closing beamage. If the file exist for any reason, it is overwritten
  • Change the title of windows to have more information
  • In graph, export of all graphs present in the window as separate items in ROOT file
  • Switched to double for counting in ROIs instead of int

[3.5]

Added

  • Export ROOT for graph
  • Display of histogram statistics (entries, mean and rms) on myPlot
  • Toggle exclusion on multiple items
  • Add Toggle exclusion to the undo command

Fixed

  • Bug correction in sample place for BQS
  • Uncertainity calculation when exclusion
  • fix bug of roi count in groups

  • Rows in reports can now be ordered by column in ascending and descending order.
  • Checkbox to lock item aspect ratio in resize item dialog.

  • Tool buttons for exclusion rectangles and ellipses.
  • Saving of image as new DAF file.

Fixed

  • Windows icons are now set directly from QApplication.
  • Crash when opening TIFF images.
  • Geometry of ROI information and annotations.
  • New image from ROI feature.

Changed

  • Cleaned myScene::mouseReleaseEvent().
  • Graphs now refresh automatically when the item is moved.
  • Release builds don't output to stdout anymore.
  • Resize item dialog now display values in �m.

Removed

  • Refresh buttons for graphs.
  • ".roi" filter when opening files.

3.2.1 - 2021-11-22

3.2 - 2021-11-03

Added

  • Ctrl + left-click + drag on a item now duplicates it.
  • Refresh buttons for graphs
  • Error messages on QDataStream operators when the version of the object is not compatible with the current Beamage version.
  • Most graphical items now use custom centralized QPainterPath to display stuff like anchors, resize handles and so on.
  • Geometry of window is now persited through sessions.
  • Resize actions added on ROIs and groups contextual menus.
  • Action on roiPolyItems contextual menus to toggle exclusion.
  • Titles on columns of XLSX exported graphs.
  • Option to display the names of group subitems.
  • Button to reset settings to default.
  • Orientation of the blur slider is set accordingly to the orientation of the blur toolbar.
  • Image cuts

Changed

  • When opening an image with the "display report at image opening" option, the image is focused instead of the report.
  • Improved performance when opening a DAF files.
  • C++ 17 is now used.
  • Most QMessageBoxes replaced by calls to QMessageBox static function information(), warning(), question() and critical().
  • Image zoomed to fit in view at opening.
  • Blur toolbar is now showed next to the palette by default.
  • imageF and imageI replaced by templated Image class
  • Slide labels that are outside the image are now displayed.

Fixed

  • Workspaces cannot be unanchored anymore.
  • Crash when copy / pasting scales.
  • Crash when adding an item to a group by clicking on the group and not and item of the group.
  • Bug with workspace controller update when the report is not generated by default.
  • Bug with workspace controller when workspaces on multiple images are used.
  • ROI toolbar shortcuts now work when the buttons are hidden.
  • Hovering graphs now displays the correct status tip.
  • Anchored items cannot be resized, rotated or flipped anymore.
  • Images and reports aren't closed anymore when the choice of saving file is cancelled.
  • Clang warnings.
  • Crash when exporting time graphs as XLSX files.
  • Hovering of resize handles and rotate handle for ROIs.
  • Bug when opening bde file with exclusion items from version prior to Beamage 3.0.

Removed

  • Items other than ROIs and groups cannot be added to a group anymore.
  • Removed approx. 700 lines of duplicated code.

3.1.2 - 2021-07-15

Fixed

  • Position of ROI names fixed when opening a BDE file.

3.1.1 - 2021-06-25

Fixed

  • Normalization of time graphs.
  • Bugs on undo/redo for workspaces.
  • Workspace item indicator rectangle for group items.
  • Negative areas when drawing ROIs counter clock-wise.
  • Exclusion areas getting negative and positive when undo / redoing the addition to the workspace.

3.1.0 - 2021-06-24

Added

  • CHANGELOG.md
  • Time graphs for workspaces.
  • Settings for time graphs.
  • Graphs can now be generated from groups of ROIs (inclusion and exclusion).
  • Workspaces now support Undo/Redo operations.
  • Shortcuts for tools in the ROI controller.
  • Shortcuts for grouping / ungrouping ROIs.

Changed

  • Calcul menu renamed to Workspace with it's submenu Amplitude renamed to Graph.
  • Positions of ROIs annotations with the ID at the top-left corner, the name at the top-right corner and the workspace ID at the bottom-left corner.
  • Sample label names are not movable anymore.

Fixed

  • Display of ROI name, id and workspace id when copy pasting ROIs.
  • Renaming an ROI from its context menu or from its annotations.
  • Crash related to graph names.
  • Amplitude histogram's bars widths now fit well.
  • Workspaces and items are now removed from the workspace controller when their corresponding image has been removed.
  • Bug with ROIs resize handles when grouping, resizing and ungrouping. Same for resizing, grouping and ungrouping.
  • On workspace creation, only the ROIs that really intersect with the workspace are proposed.
  • Reports are now correctly updated when renaming groups from the image.
  • Display of items names when copying groups.
  • Bounding rect of group items.
  • Crash when undoing after having displayed and hidden some group's name.

3.0.2 - 2021-06-07

Added

  • Option in preferences to configure automatic smoothing on freehand drawn ROIs.

3.0.1 - 2021-06-01

Fixed

  • Smoothing of ROIs is now only done for freehand drawn ROIs.

3.0.0 - 2021-04-02

Added

  • Statistical error section to reports.
  • Amplitude workspaces.
  • Amplitude histograms.
  • Holding Shift + Left Click when resizing and ROI locks its aspect ratio.
  • Auto update system.

Changed

  • InnoSetup replaced by Qt Installer Framework for auto updates.
  • Preferences window now closes automatically when clicking the Ok button.

Fixed

  • Performance issue when a large number of ROIs are created.
  • Bug when opening image from existing image with the No ROI option selected.
  • Bug when opening and saving old .bde files.
  • Bugs with undo/redo operations.
  • Bug when changing window while drawing an ROI.
  • Crashes when using the separation workspace toolbar buttons without a workspace.

Removed

  • Beamage configurator and configuration file, that let the user hide or show the Calcul menu. The menu is now always shown.
