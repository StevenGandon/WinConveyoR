Releases all resources owned by an HTTP request parser.

Frees every header pair, the protocol, method, route strings, and the parser struct itself. The associated connection is not closed.

Parameters
[in]parserParser to destroy. No-op if NULL.

Skips the status line and iterates over each Key: Value\r\n line, storing every pair via set_header into parser.

◆ read_http_headers()

unsigned char * read_http_headers ( struct _http_connection_s *  client,
size_t *  total_size 
)

Reads raw response data from the connection until the header terminator (\r\n\r\n) is found.

Accumulates chunks until the end-of-headers sequence is detected. The returned buffer is heap-allocated and null-terminated; total_size is set to the number of bytes up to and including the terminator.

Parameters
[in]clientConnection to read from.
[out]total_sizeSet to the length of the returned buffer on success.
Returns
Heap-allocated buffer containing the raw header block, or NULL on failure. The caller is responsible for freeing it.
