Compilation

To compile the project you will need to do the installation step if not already done: Installation Steps

Compiling the documentation

  • Install (if not done) doxygen.
    Via the command line (powershell.exe, cmd.exe, ...):
    Windows:
    winget install -e --id DimitriVanHeesch.Doxygen
    Debian based:
    sudo apt-get install doxygen texlive -y
    Arch based:
    sudo pacman -S doxygen texlive
    Fedora based:
    sudo dnf install doxygen texlive
    Via the GUI installer:
    Windows: Download link

  • Open the terminal emulator of your choice with the shell of your choice.
  • Locate the project and get the full path.

  • Enter in the terminal:

    Windows:
    cd /d the\full\path\you\got
    GNU/Unix like:
    cd the/full/path/you/got
    Windows:
    doxygen .\doc\doxygen\doxydoc
    GNU/Unix like:
    doxygen ./doc/doxygen/doxydoc
  • The documentation is now compile as HTML at ./doc/doxygen/html/
    You can now view it on your webbrowser directly, host it locally or even host it on a dedicated server.
    To view it directly just go to ./doc/doxygen/html/ and click on any html file (preferably index.html) and the documentation should open on your default webbrowser.
    To run it on a dedicated/local server there are a lot of opensource http webserver out here that you can use like for exemple Apache or NGinx, after running the http server you just need to copy everything in the ./doc/doxygen/html/ to the webserver serving directory (usually someting like /var/www/html/), but like said before it's not a mandatory step, it's an option.

Compiling the libraries

  • Locate the repository installation path on your machine (to install the repository go to the Installation guide)
  • Pull the latest version of the repository :
    Via the command line:
    git checkout BRANCH_NAME # <- is this case likely `develop` or `master`
    git pull
    Via the GUI: Select the repository and fetch/pull the branch you're working on.
  • Start the project in visual studio
    Via the command line:
    start devenv .\Beamage.sln
    Via the file explorer: In your file explorer double click the Beamage.sln file.
  • Now in the Solution Explorer (likely the tab on the right, ressembling a file tree) right click the library you want to compile (for exemple BeamageStream or BeamageGraphic) and click Project Only > Build only LIBRARY_NAME to build it as a standalone library and Build to link it to the whole solution.
  • The libraries should now be compiled to .\x64\... .

  • Locate the repository installation path on your machine (to install the repository go to the Installation guide)
  • Pull the latest version of the repository :
    Via the command line:
    git checkout BRANCH_NAME # <- is this case likely `develop` or `master`
    git pull
    Via the GUI:
    Select the repository and fetch/pull the branch you're working on.
  • Start the project in visual studio
    Via the command line:
    start devenv .\Beamage.sln
    Via the file explorer:
    In your file explorer double click the Beamage.sln file.
  • On the top menu bar click Build > Build Solution.
  • The executable should now be compiled to .\x64\... .
