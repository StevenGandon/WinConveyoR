vm_handler_t vm_find_handler ( uint16_t  version,
const char *  name 
)

Looks up the handler for the given instruction name and format version.

Selects the most recent handler table whose version does not exceed version, then searches linearly for a matching name.

Parameters
[in]versionFormat version of the .WIZARD file being executed.
[in]nameNUL-terminated instruction mnemonic to look up.
Returns
Pointer to the handler function, or NULL if not found.
