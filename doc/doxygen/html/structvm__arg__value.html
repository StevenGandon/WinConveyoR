Detailed Description

A decoded argument value produced by vm_decode_arg.

The active union member is determined by type.base. When type.is_array is non-zero, count gives the number of elements and each pointer addresses a heap-allocated array of that many values. When not an array, count is 1 and the pointer addresses a single-element heap-allocated array.

Call vm_free_args to release all memory owned by decoded argument arrays.
